## 魔域2.4变态版 打包 EXE 无声音 —— 根因定位

**结论：不是打包的问题，是这个 SWF 的双层结构 + AS3 壳加载 AS2 影片导致的。**

- 外层 `魔域2.4变态版_71214.swf`（CWS v10，14.3MB）：**AS3 壳**，231 个标签，DefineSound/SoundStreamHead/SoundStreamBlock **全部为 0**，唯一实质内容是 1 个 `DefineBinaryData`（CharacterId 207，13.43MB），里面以 `CWS` 开头 = **内嵌了一整个第二层 SWF**。
- 内层 SWF（CWS **v8**，解压后 16.2MB）：**AVM1 (AS2)** 的真正游戏，含 **41 个 MP3 音效（11025Hz）+ 1 条 MP3 流（SoundStreamHead2）**，10 个 DoAction。
- 运行方式：外层 AS3 壳用 `Loader.loadBytes()` 把内层 AVM1 SWF 挂成 `AVM1Movie`。Flash Player 上 AS3 容器里的 AVM1Movie **音频经常丢**（AVM1 音频走独立通路，standalone player 上不回放）；Ruffle 把它当普通影片树挂载走 WebAudio，所以**本工具有声、Flash Player 打包后无声**。
- 佐证：用户用 2013 年的 `Flash播放器.exe` 打开同一 SWF 也**没有声音** → 两个不同版本 Flash Player 都无声，排除系统 waveOut 环境问题，指向播放器行为差异。

**解法**：把内层 SWF 提出来直接用（单文件 AS2，音频齐全），再打包 EXE 就有声。
已写临时脚本 `%TEMP%\extract-inner-swf.mjs`，产物 `魔域2.4变态版_71214-真实游戏(AS2).swf`（FWS v8，15.47MB，41 个 DefineSound ✓）。

## 本项目的其他事实

- 下载目录：`%APPDATA%\flash-game-trainer\games\`（用 package.json 的 **name**，不是 productName）；
  游戏库索引 `data\games.json`、修改配置 `data\profiles.json`。
  打包产物 app.asar 内 package.json 是 `name=flash-game-trainer` / `productName=undefined`，
  **改 productName 为「闪电Flash」不会改变 userData 路径**，老数据不丢。
- 内置播放器 `resources/flash-projector.exe`：10.7MB，版本资源 `34,0,0,192`，音频输出用 **waveOut**
  （waveOutGetDevCapsW / waveOutPrepareHeader / timeKillEvent），编解码字符串含 MP3 / NellyMoser / SPEEX / Microphone，音频能力完整。
- 本工具打包的 EXE 可用页脚魔数 `0xFA123456` 识别：
  `闪客快打5中文无敌版_64918.exe`(15.5MB)、`ylcs.exe`(28.6MB) 是本工具产物；
  `TT.exe`(14.0MB) 与 `Flash播放器.exe`(9.8MB) 不是。
- `preload` 里的 `showFileInFolder`（`shell.showItemInFolder`）目前无界面调用，是死接口。

## 分析工具（临时脚本，均在 %TEMP%）

- `analyze-swf-audio.mjs` — 解压 SWF + 标签统计 + 音频格式
- `verify-swf.mjs` — 校验头长度自洽 + 精确 MP3 流检测（连续 8 帧等长校验，避免随机误报）
- `dump-bindata.mjs` — 导出 DefineBinaryData
- `analyze-inner.mjs` / `extract-inner-swf.mjs` — 内嵌 SWF 分析与提取
