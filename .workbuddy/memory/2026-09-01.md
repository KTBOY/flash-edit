# 2026-09-01

## 闪电Flash 品牌化 + 打包模式 + 启动/交互修复（flash-edit）

- 品牌：`productName` 改「闪电Flash」，`win.artifactName` → `闪电Flash-v${version}-${arch}.${ext}`；窗口 title 与 index.html title 同步。
- 启动闪烁根因：`ready-to-show` 只保证文档首帧，React 挂载 + antd v5 cssinjs 运行时注入样式这段空窗期窗口是空的。修复 = index.html 内联静态骨架 `#boot`（必须是 `#root` 的**兄弟节点**，React 只接管 #root；样式必须内联，global.css/antd 样式都是 JS 注入的）+ main.tsx 双 rAF 后淡出移除。
- Tab 栏「滑动」根因：rc-tabs 在 nav 三层挂 resize-observer，`.scroll-panel` 把 nav 和内容包进同一滚动容器，滚动条显隐改变容器宽度 → needScroll/transformMin 翻转 → `.ant-tabs-nav-list` transform 跳变 + `.ant-tabs-ink-bar-animated`（transition .3s）下划线滑动。修复 = 滚动容器下沉：`.panel-tabs` nav 固定、只有 `.ant-tabs-content-holder` 滚动（ScanPanel/CheatListPanel 无自带滚动容器，必须由 content-holder 承接）。另抽 `ProfileAutoSaver` 切断 AppShell 对 speed 的订阅，HudSlider 加 rAF 合并。
- 打包模式：`useModeStore`（localStorage `fgt.mode.v1`），默认 `fullMode=false`（精简：隐藏下载游戏按钮、下载新游戏、扫描/修改列表 Tab）+ `siderOpen=false`（侧边栏收起）。密令 `test` 在 设置→关于区 `UnlockInput` 输入，永久解锁。密令只防误触，无安全强度，故放渲染层。
- 游戏库从标题栏下拉迁到侧边栏 Tab；标题栏新增折叠按钮（`MenuFold/Unfold`，靠 `.hud-header .ant-btn` 的 no-drag 规则可点）。侧边栏用条件渲染 `<aside className="panel">` 而非 Sider width:0。
- 新增 IPC `SHELL_OPEN_EXTERNAL`（`ipcMain.on` + `shell.openExternal`），**必须 http/https 白名单**（`new URL(url).protocol`），preload 用 `send` 单向。
- 坑：`dist/win-unpacked` 旧文件被占用导致 electron-builder `remove ... Access is denied`（无 electron 进程在跑，疑似环境锁定）→ 用 `-c.directories.output=<temp>` 打到临时目录绕开。
- **最终解（打包锁）**：`app.asar` 锁持续数小时且系统无相关进程（资源管理器预览窗格/杀软类隐形占用，重试+杀进程都解不掉）。定案 = `build.directories.output` 迁到 **`dist/build`**（全新目录不撞锁）+ 新增 `scripts/clean-dist.mjs` 挂 `predist`/`clean`（只杀 ExecutablePath 在本项目 dist 内的进程 + `fs.rm maxRetries:6` 带重试 + 失败列文件给中文指引）。修复后 `npm run dist` 成功产出 `dist/build/闪电Flash-v0.1.0-x64.exe`。旧 `dist/win-unpacked` 仍锁，重启后手动删。
- 坑：本环境 `ELECTRON_RUN_AS_NODE=1` 被设置，`electron.exe out/main/index.js` 会以纯 Node 运行报 `app.requestSingleInstanceLock` undefined，无法在会话内冒烟启动 Electron 窗口。
- 坑：`.mjs` 脚本里不能写 TS 类型标注（`function f(): void` 直接 SyntaxError），node 不会为 .mjs 做类型剥离；scripts/ 下的脚本要纯 JS。
- 坑：本会话 spawnSync `ping` 会触发沙箱拦截（系统级工具），脚本里延时用 `setTimeout` promise 替代。
- 遗留：第 7 条「打包速度慢」用户跳过，分析结论已写在计划文件 §7 备查。
