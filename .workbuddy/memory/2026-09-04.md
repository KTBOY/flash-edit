# 2026-09-04

## 安装包改为带向导、可选安装目录

- 需求：打包后双击安装直接装 C 盘（`%LOCALAPPDATA%\Programs`），要求能选目录。
- 根因：`package.json` 里没有任何 `nsis` 配置 → electron-builder 默认 `oneClick=true / perMachine=false` = 一键安装、无目录页。
- 改动：新增 `build.nsis` 段：
  `oneClick:false`（带向导）、`perMachine:false` + `selectPerMachineByDefault:false`（默认「仅为我」）、
  `allowElevation:true`、`allowToChangeInstallationDirectory:true`（目录页）、
  `installerLanguages:["zh_CN"]` + `displayLanguageSelector:false`（中文向导）、
  快捷方式/装完运行默认、`deleteAppDataOnUninstall:false`（卸载保留游戏库与配置）。
- 验证：重跑 `npm run dist` 日志出现 `oneClick=false perMachine=false`。

## 追加：安装完成页「运行程序」提示

- 其实 `runAfterFinish:true` 就会产生完成页勾选框；本次进一步用 **`build/installer.nsh`**
  （electron-builder 自动 include 的 buildResources 自定义脚本）定制完成页：
  `MUI_FINISHPAGE_TITLE "安装完成"`、`MUI_FINISHPAGE_TEXT`、`MUI_FINISHPAGE_RUN_TEXT "运行 闪电Flash"`。
- **关键事实**：MUI2 的运行勾选框**默认就是勾选的**（Finish.nsh 里 `!ifndef MUI_FINISHPAGE_RUN_NOTCHECKED → BM_SETCHECK BST_CHECKED`），
  网上常说的 `MUI_FINISHPAGE_RUN_CHECKED` 并不存在，多余定义无害但无效。
- **验证方法（重要教训）**：NSIS 字符串表是**压缩存储**的，无法在安装包 exe 里明文 grep 中文；
  之前 `grep -a -c $'\x0b\x4e...'` 得到的 1960 次是**误报**（bash 的 `$'...\x00...'` 会丢弃 NUL 字节导致模式错位）。
  正确做法：electron-builder 的 `DebugLogger` 默认启用，完整生成的 .nsi 会写进
  **`<output>/builder-debug.yml`**（本项目 `dist/build/builder-debug.yml`），
  在里面能查到 `!include ".../build/installer.nsh"`、`MUI_LANGUAGE "SimpChinese"` 等真实脚本行。
- 框架限制：`oneClick:false` 且 `perMachine:false` 时，assistedInstaller.nsh 必然插入 `PAGE_INSTALL_MODE`
  （只有 `INSTALL_MODE_PER_ALL_USERS` 即 perMachine:true 才跳过），「安装模式」页去不掉。
- 注意：本会话沙箱会拦截子进程写 `Recent\CustomDestinations`，导致 `npm run dist` 的 tail 以"failed"退出，但产物已正常生成（看日志与文件时间戳判断，别被 exit code 骗了）。
- 文档：`docs/USAGE.md` 新增「安装与卸载」一节。
