# 使用教程（Cheat Engine 工作流）

## 准备

```bash
npm install     # 会自动复制 Ruffle 运行时（postinstall）
npm run dev     # 启动开发版
npm run dist    # 生产构建 + 打包 Windows 安装包（内置 electron-vite build，无需先单独 build）
```

打包产物统一输出到 `dist/build/`：安装包 `闪电Flash-v{版本}-x64.exe`（含 `.blockmap`）、
免安装裸程序目录 `win-unpacked/`（直接跑 `win-unpacked\闪电Flash.exe`）。
输出目录由 `package.json` 的 `build.directories.output` 配置，每次打包前由 `npm run clean`
（`predist` 自动触发）清空——若上次打包后程序还开着，清理会自动结束旧进程再删。

## 安装与卸载

`npm run dist` 产出 NSIS 安装包 `dist/build/闪电Flash-v{版本}-x64.exe`，双击后是**带向导的安装界面**（中文）：

1. **安装模式**：默认选中「仅为我安装」——直接下一步即可，**不弹 UAC、不需要管理员**；
   需要装到 `C:\Program Files` 这类受保护目录时，勾选「为所有用户安装」才会申请提权；
2. **安装位置**：默认 `%LOCALAPPDATA%\Programs\闪电Flash`，可改成任意目录（如 `D:\游戏\闪电Flash`）。
   若所选目录末尾不含程序名，安装器会自动补一层 `闪电Flash` 子目录；
3. **完成页**：标题为「安装完成」，提示文案下方是**默认已勾选的「运行 闪电Flash」**——
   直接点「完成」即可立即打开程序开始使用；
4. 勾选项：桌面快捷方式、开始菜单快捷方式、安装后立即运行。

卸载走「Windows 设置 → 应用」，**默认保留用户数据**（已下载的游戏与修改配置），
如需连同数据一起清除，卸载后手动删除 `%APPDATA%\flash-game-trainer`。

> 用户数据目录是 `%APPDATA%\flash-game-trainer\`（取 package.json 的 `name`，与界面上的
> 品牌名无关）：`games\` 存下载的游戏，`data\games.json` 是游戏库，`data\profiles.json`
> 是按游戏哈希自动恢复的修改配置。

## 加载游戏

四种方式任选：

1. **打开 SWF**：系统文件选择框（支持 `.swf` / `.spl`）；
2. **拖拽**：把 `.swf` 拖进左侧播放器区域；
3. **网络加载**：输入 http(s) 的 SWF 地址（需目标站允许跨域）；
4. **下载游戏**：从 [oldswf.com](https://oldswf.com) 或 [gamebox.tw](https://www.gamebox.tw) 下载（见下一节）。

加载后左下状态栏会出现"WASM 内存块"，出现即代表修改器已就绪。

## 下载游戏（oldswf.com / gamebox.tw）

两个站点各自做了不同的取源限制，直接把 SWF 地址喂给「网络加载」或下载工具都会失败：

- **oldswf.com**：对网页响应做 **TLS 指纹级反爬**，非真实浏览器一律 403；游戏页里的
  资源路径也不按游戏 ID 走规律。
- **gamebox.tw**：游戏本体放在对象存储上，只认来源页属于 `https://www.gamebox.tw/` 的
  请求（缺 Referer 一律 403，连 HEAD 都不给），文件名为上传时间戳。

因此应用内置下载入口：**侧边栏「网络下载」面板**。面板顶部先选站点，
每个站点是独立入口——各自的输入框、格式说明与任务列表，互不混用，
纯数字 ID 也不会被两个站点抢（同名的 `1` 在两边是不同的游戏）。

1. 选站点，输入游戏页地址（如 `https://www.gamebox.tw/game/8067`、
   `https://oldswf.com/game/109087`）或该站点的纯数字 ID（`8067`），点「加入队列」；
2. oldswf 会以无头模式驱动**本机已安装的 Edge/Chrome** 打开游戏页，读出资源地址后
   直连下载，失败再退回监听站点自身的分片下载并重组（约 1~2 分钟，取决于网速）；
   gamebox 直接带 Referer 全量拉取，不需要浏览器，通常几秒到几十秒；
3. 下载完成后文件按 `游戏名_站点游戏ID.swf` 保存到设置的下载目录并自动计入游戏库
   （下次直接在游戏库点「打开」即可重玩），任务行上的「打开」可立即载入。

说明：oldswf 下载需要系统装有 Edge 或 Chrome（Windows 10/11 自带前者）；两个站点
共用下载队列，最多 3 个任务同时跑，其余排队，进行中可「取消」，失败直接「重试」；
「删除选中」只清任务列表，不动游戏库与磁盘文件。下载保存位置在「设置 → 下载设置」
里查看，可「修改位置」，也可「打开位置」直接在资源管理器里打开该目录。
仅建议下载本身允许免费游玩的游戏资源。

## 修改血量/金钱（标准四步）

以"金币 100 → 想改成 99999"为例：

1. **首次扫描**：扫描面板输入 `100`，方式选「精确值」，点「首次扫描」。
   会得到一批候选地址（通常是几千个）。
2. **改变数值**：回游戏里花掉/获得一些金币，让金币变成一个新值，比如 87。
3. **再次扫描**：输入 `87` 再点「再次扫描」→ 候选骤减；重复 2~3 轮通常收敛到个位数。
   - 不知道精确值时：方式选「增大了 / 减小了 / 变动了」；
   - 完全不知道初始值：首扫直接选「未知初始值」建立基线，之后用「增大/减小/变动」收敛。
4. **修改/锁定**：
   - 「写入」：填新值点写入，立即生效；
   - 「锁定」（挂锁图标）：加入修改列表并持续写回——无敌、不减金币用这个；
   - 「全部写入」：把剩余所有候选一次写成同一个值（收敛到少量候选后的暴力手段）。

误删误扫可点「撤销本次」回退一步（最多 5 步）。

## 修改伤害

- **改攻击力属性**（推荐）：属性是持久变量，流程与金钱完全相同；
- **抓单次伤害结算值**：伤害是瞬态值。先记住打出的数字，选「未知初始值」首扫，
  再打一次，用「精确值 / 介于」在结算瞬间连扫收敛。扫不到时退回改属性。

## 打包 EXE（Flash 转 EXE）

把任意 SWF 变成双击即玩的单文件 EXE：**头部「打包 EXE」按钮**。

- **来源**：当前加载的游戏，或点「选择 SWF」选任意本地文件；
- **输出路径**：点「生成 EXE」后弹出系统另存对话框，保存位置由你自行选择
  （默认文件名 = 弹窗里的「输出名」），应用没有固定输出目录；
- **播放器**：默认内置 Flash Player 32 独立版（随应用分发，位于 `resources/flash-projector.exe`）；
  也可选择你自己的 projector EXE；
- **原理**：Flash 独立播放器原生支持读取附加在自身末尾的 SWF，文件结构为
  `[播放器] + [SWF] + [魔数 0xFA123456] + [SWF 长度]`，拼接后即得自运行 EXE；
- 生成的 EXE 约 10MB（播放器体积）+ SWF 大小，直接双击运行，无需任何安装。

想分发**修改版游戏**：先「写入 SWF」生成补丁文件，再用「打包 EXE」选择该文件打包。

## EXE 还原（提取 SWF）

「打包 EXE」的逆向操作：头部「打包 EXE」打开弹窗 → 模式切到 **「EXE → SWF（还原）」** →
选择 EXE，应用读取其尾部 8 字节 projector 页脚（魔数 `0xFA123456` + SWF 长度）定位
附加的 SWF，另存为 `.swf` 文件并自动载入游戏（可直接进入扫描修改流程）。

- 支持**本工具打包的 EXE**，以及任何按 Flash projector 结构封装的 EXE
  （包括 Flash 独立播放器"文件 → 创建播放器"生成的）；
- 不支持 Zinc / SWF Studio 等第三方封壳（它们的内部结构不同，尾部无该页脚）；
- 典型用途：手里只有别人给的双击即玩 EXE，想拿回 SWF 修改数值或重新打包。

## 写入 SWF（把修改固化为永久修改）

运行时修改在重启游戏后失效；想得到一个"天生就是修改版"的 Flash 文件，用
**修改列表 →「写入 SWF」**：

1. 像往常一样扫描并修改数值后，进入修改列表，点「写入 SWF」；
2. 弹窗中每条修改显示 **原值 → 新值**。原值是进入列表时的数值，可手动修正
   （写入 SWF 靠"在文件里找到等于原值的常量"来定位，所以原值必须准确）；
3. 点「分析命中」——显示每个修改在文件里命中的常量个数：
   - 命中 ≥1：可以固化；
   - 命中 0：文件里没有这个值的常量（数值是运行时算出来的，或以小整数指令内联），
     这类修改无法固化，属正常现象；
4. 点「另存为…」生成 `xxx_modified.swf`（不覆盖原文件），用本工具或浏览器打开验证。

原理与边界：AS3 游戏改写 ABC 常量池（double 池 + 整数池），AS2 老游戏按双精度
字节匹配；运行时计算得出的数值（如 攻击力×等级）不会被固化。网络加载的游戏
没有本地文件，不支持此功能。

## 变速

设置页 → 变速齿轮，滑杆 0.1x–10x（0.1–5 为常用区）。对帧循环与计时器驱动的游戏生效。

## 项目 Skill 面板

侧边栏「Skill」页签列出**当前项目**的 Agent Skill（`SKILL.md`），用来确认「这套流程到底有没有被读到」：

1. 扫描仓库内的 `.agents\skills\` 与 `.qoder\skills\` 两处（开发时取仓库根，安装版取 exe 同级目录）；
2. 按名称/描述搜索，改动 skill 文件后点右侧刷新按钮重扫；
3. 点条目名称看 `SKILL.md` 正文（只读，超长截断）；行尾两个图标分别是**复制 skill 目录路径**（贴给 AI 会话直接引用该 skill）与在文件夹中显示；
4. 同名 skill 在项目内两个目录里都有时，条目右侧给出提示图标——谁真正生效由 Qoder 决定，本面板只提醒不代删。

说明：扫描与读文件都在主进程完成，且只允许读取上述扫描根内的 `SKILL.md`；面板不写入任何 skill 文件。全局目录（`%USERPROFILE%\.qoder\skills\`）与插件自带的 skill 不在本面板范围内。

## 输出路径与日志

| 操作 | 输出位置 |
| --- | --- |
| 下载游戏（oldswf / gamebox） | 设置里的下载目录，默认应用数据目录 `games\`（如 `%APPDATA%\flash-game-trainer\games`），可在「设置 → 下载设置」用「打开位置」直接打开 |
| 打包 EXE / EXE 还原 / 写入 SWF | 系统另存对话框自选，无固定目录 |

所有产出文件的完整路径都会实时写入**应用日志**：应用数据目录下的 `logs\app.log`
（如 `%APPDATA%\flash-game-trainer\logs\app.log`，超过 2MB 自动轮转为 `app.old.log`）。
打包安装版没有控制台，找不到输出文件时查日志即可。

## 修改配置（存档）

- 每个游戏的修改列表和速度会按**游戏内容指纹自动保存**（`userData/data/profiles.json`），
  下次打开同一游戏自动恢复；
- 重启游戏后内存布局可能变化，恢复时会自动校验：地址读不到的条目标记「地址失效」并自动解锁，
  重新扫描后重新锁定即可；
- 扫描出的地址只在**本次会话内**稳定，这是与 Cheat Engine 一致的已知限制。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 扫描很慢 | 首扫需遍历全部 WASM 内存（数百 MB），正常几秒内；后续再扫只过滤候选，很快 |
| 候选数降不下来 | 换更独特的数值（如金钱 1234 而不是 0/100），或用「变动/未变动」代替精确值 |
| 改了没效果 | 该游戏可能校验数值（加密/双存储），尝试锁定 + 连续改，或放弃该值 |
| 小数扫不到 | 设置页把浮点容差放宽到 1e-3（单精度小数场景） |
| 游戏跑不起来 | Ruffle 兼容性问题，可到 Ruffle 上游反馈；本项目依赖其模拟完备性 |
