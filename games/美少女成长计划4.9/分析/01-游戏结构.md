# 01 — 游戏结构（三层包装拆解 + 帧地图）

## 一、三层包装结构（4399 平台壳）

原文件 `美少女成长计划4.9版本_无限金钱版.swf` 是一个 **4399 三层嵌套包装**，
真正游戏本体藏在最内层。拆解顺序：

```
第 1 层（外层，AS3 壳）
  System4399Manager —— 加载 4399 ctrl_mo_v2.swf，失败则离线运行
    └─ 内嵌 binaryData chid=3: L4399Main_gamefile.bin (12.757 MB)
        第 2 层（AS3 壳）
        DressUp_4399_Main
          └─ 内嵌 binaryData chid=3: DressUp_4399_Main_gamefile.bin (12.635 MB)
              第 3 层 = 游戏本体（AS2，SWF v10）
              640×480 · 26fps · 主时间轴 11 帧 · 反编译脚本 454 个
```

**判断包装壳的特征**：体积大（12MB）+ 主时间轴帧数极少（2~11 帧）+ 有 `loadBytes` 特征。

**拆解命令**（重复 `-export binaryData` 直到出现中文变量名的 AS2 本体）：

```bash
JAVA="C:/Program Files/Java/jdk1.8.0_102/bin/java.exe"
FF="D:/game/test/tools/ffdec/ffdec-cli.jar"
"$JAVA" -jar "$FF" -export binaryData <outdir> <wrapper.swf>   # 最大那个 .bin 就是下一层
```

## 三、脚本反编译产物命名规律

`-export script` 后目录结构（中文标识符 = 全局变量，挂 `_root`）：

```
frame_N/DoAction*.as                       # 主时间轴各帧脚本（一帧多个脚本按 DoAction、DoAction_2… 顺序执行）
DefineButton2_<id>/BUTTONCONDACTION on(release).as   # 按钮动作
```

- **中文标识符** = 全局变量/函数（游戏自己的，挂 `_root`）
- **`_locN_`** = 反编译出的局部变量
- **目录里没有 .as 的按钮 = 空动作按钮**（这正是首页「读取记忆」chid 159 的情况）
