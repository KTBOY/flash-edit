## 三、存档系统设计要点

见 `补丁/scripts_final2/frame_1/DoAction.as` 完整实现。核心结构：

1. **载体**：`SharedObject.getLocal("meishao49_local_save")`，3 槽位 + 最后槽位。
2. **生成**：显式变量表（200 项）+ `for...in` 兜底 + 数组表（整体复制）。
3. **读档 = 延时应用**（最关键）：
   ```as2
   执行读档(槽位) {
      d = 存档_读数据(槽位);
      _root.存档_待应用数据 = d;
      移除系统设置面板;
      _root.gotoAndStop(11);      // 进入会触发游戏自己的 初始女儿状态() 重置
      存档_等待应用();             // setInterval 轮询，等初始化完成后覆盖
   }
   ```
4. **应用后恢复 UI/外观**（for-in 覆盖不到的部分）：
   ```as2
   if (typeof(_root.主面板.更新) == "function") _root.主面板.更新();   // ★ 不调则 HUD 名字显示 undefined
   // 换装游戏：外观帧显式恢复
   女儿人物.gotoAndStop(年龄阶段帧);   // 年>=1768→3, >=1766→2, 否则→1
   女儿人物.人.gotoAndStop(_root.衣服);
   背景1.gotoAndStop(季节帧);         // 1~4
   ```
5. **首页读档**（自由选槽位）：
   ```as2
   function 读取记忆首页() {
      _root.attachMovie("系统设置","系统设置",220,{_x:0,_y:0});
      _root.系统设置.gotoAndStop(4);   // 直达读档页
      _root.延迟刷新标题();
   }
   ```
   复用游戏自带「系统设置」面板（其内部按钮是作者时按钮，Ruffle 下点击可靠）。

## 四、关键坑（每个都踩过）

| 坑 | 结论 |
|---|---|
| **Ruffle 中自绘 MC 按钮点不动（系统性）** | 不要用 `createEmptyMovieClip`+绘图做按钮；复用游戏自带按钮符号/面板，或用鼠标坐标判定 |
| 槽位按钮同 chid 放 3 次、注入动作相同 | 用鼠标局部坐标判槽位：`局部y = _root._ymouse - 面板._y`（**动态算，勿硬编码偏移**） |
| 首页挂面板后，存档保护误拦读档 | 保护条件加 `&& 面板._currentframe != 4`（放行读档页） |
| 读档后 HUD 显示 undefined | 存档应用后**再调** `_root.主面板.更新()` |
| 换衣服没保存 | 只存了标量 `衣服`，漏了数组 `所有衣服`/`商店的衣服` → 单独数组表 |
| 外观帧不恢复 | `_currentframe` 不是 `_root` 变量 → 显式 `gotoAndStop` 恢复 |
| 提示框不消失 | 只清文字不够（边框残留）→ 2000ms 后整条 `_visible=false` + `selectable=false` |
| 提示框要手动关 | 加 ✕ 按钮（用游戏自带 `工作名称` 按钮符号，改其 `岗位.text`） |
| FFDec 中文长文件名 `-replace` 报 I/O error | 中间步骤用 ASCII 短名，成品再改回中文 |
| FFDec `BUTTONCONDACTION` 属性 `condOverUpToIddle` 是**双 d** | 写错会让 xml2swf 抛异常但**仍写出残缺 swf**（退出码 0）→ 必须 grep `SEVERE` |

## 五、字体（Ruffle 下可见性）

- 运行时文本必须用**游戏内嵌字体**：`格式.font = "FZCuQian-M17S"`
- 内嵌字体是**子集**，缺失字形静默丢字 → 消息串写「中文 + 小写 ASCII」兜底；
  可靠的字符：数字、小写字母、空格、`/`、`:`；**大写字母/括号/连字符不一定在子集里**。
