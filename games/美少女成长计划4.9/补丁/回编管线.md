# 回编管线（从脚本重建成品）

把 `scripts_final2/` 的补丁脚本重新编译进成品 SWF 的完整命令。
所有命令已在《美少女成长计划 4.9》实测通过。

## 一、环境变量

```bash
JAVA="C:/Program Files/Java/jdk1.8.0_102/bin/java.exe"
FF="D:/game/test/tools/ffdec/ffdec-cli.jar"
PY="C:/Users/zhou/.workbuddy/binaries/python/versions/3.13.12/python.exe"
SKILL="D:/my/flash-edit/.agents/skills/flash-game-patcher"
```

## 二、完整管线（六步）

```bash
# ① 反编译游戏本体（第 3 层）为 XML —— 拿 l3_full.xml
"$JAVA" -jar "$FF" -swf2xml game_l3.swf l3_full.xml

# ② 注入按钮动作（两个）—— 用 skill 自带脚本
"$PY" "$SKILL/scripts/inject_action.py" l3_full.xml 159  <读取记忆首页的hex> l3_patched.xml
"$PY" "$SKILL/scripts/inject_action.py" l3_patched.xml 1039 <处理槽位点击的hex> l3_patched2.xml

# ③ XML 回编 SWF
"$JAVA" -jar "$FF" -xml2swf l3_patched2.xml stage1.swf

# ④ 脚本补丁（importScript，只能替换已存在脚本）
"$JAVA" -jar "$FF" -importScript stage1.swf stageF.swf scripts_final2

# ⑤ 逐层回嵌（从最内层往外替换；chid=3 是内嵌 SWF 的编号）
#    内层容器 = 第 2 层 DressUp_4399_Main（先拿 ASCII 短名绕过中文长名 I/O error）
"$JAVA" -jar "$FF" -replace inner_game.swf inner_patched.swf 3 stageF.swf
"$JAVA" -jar "$FF" -replace orig_outer.swf out_final.swf 3 inner_patched.swf

# ⑥ 成品改回中文名交付
mv out_final.swf "美少女成长计划4.9版本_无限金钱版(带存档).swf"
```

## 三、回嵌细节

- `-replace <容器swf> <输出swf> <chid> <新内容文件>` —— 把容器里 `chid` 号内嵌资源替换为新文件。
- 内嵌资源 chid **先用 `-export binaryData` 确认**（产物文件名形如 `3_xxx.bin` ⇒ chid=3）。
- 逐层：`游戏本体 → 第2层容器 → 第1层外层容器`。

## 四、验证替换正确

```bash
"$JAVA" -jar "$FF" -export binaryData verify inner_patched.swf
md5sum verify/3_*.bin stageF.swf     # 应一致
```

## 五、关键注意

1. **永远不覆盖原版**：`-replace` 输出写新文件名；中间产物按 stage 编号命名便于回退。
2. **中文长文件名会让 `-replace` 报 `I/O error during reading`**（FFDec 偶发）：
   中间步骤一律用纯 ASCII 短名（`orig_outer.swf` / `inner_patched.swf` / `out_final.swf`），
   最后再 `mv` 回中文名。
3. **`-xml2swf` 成功不代表没出错**：FFDec 遇到属性名错误（如 `condOverUpToIddle` 写成单 d）
   会打印 `SEVERE: NoSuchFieldException` 但**仍写出残缺 swf 且退出码 0** —— 必须 grep 输出里的 `SEVERE`。
4. **`importScript` 只能替换已存在脚本**：新增的 `frame_1/DoAction.as` 里的存档函数是**追加在原脚本末尾**，
   不是新建文件（新建会被静默忽略）。
5. 注入用的 hex 字节码用**借用编译法**获取（见项目 Skill `flash-game-patcher/scripts/harvest_action.py`），不要手写。
